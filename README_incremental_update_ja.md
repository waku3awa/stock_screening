# 東証プライム株価データ - 差分更新機能

## 概要

既存の東証プライム全銘柄株価データ収集スクリプトに、**差分更新機能**を追加しました。これにより、既存データの最新日付から現在までの差分のみをダウンロードし、効率的にデータを更新できます。

## 新機能

### 1. 差分更新モード
- **既存データの最新日付を自動検出**
- **差分期間のみダウンロード**（通信時間・処理時間を大幅短縮）
- **新旧データの自動マージ**（重複削除・日付順ソート）

### 2. 統計情報の表示
- 総銘柄数、更新済み銘柄数、新規データ件数、エラー数を表示
- 成功率を計算して表示

### 3. 既存フローとの完全互換性
- バッチ処理、統合処理はそのまま利用可能
- ディレクトリ構造・ファイル命名規則を維持

## 使用方法

### 差分更新実行
```python
# load_yfinance.py の95行目
INCREMENTAL_UPDATE = True  # 差分更新モード
```

### 全期間ダウンロード実行
```python
# load_yfinance.py の95行目
INCREMENTAL_UPDATE = False  # 全期間ダウンロード
```

## 主要な実装関数

### `get_latest_date_from_parquet(file_path)`
- 既存parquetファイルから最新日付を取得
- Date列のみ読み込みでメモリ効率を最適化
- ファイル不存在・エラー時は None を返す

### `merge_and_save_data(existing_file, new_data, ticker)`
- 既存データと新規データをマージ
- 日付ベースで重複削除（新しいデータを優先）
- 日付順ソート後、parquet形式で保存

## 処理フロー

1. **差分更新モード判定**
   - `INCREMENTAL_UPDATE = True`の場合、差分更新を実行

2. **各銘柄に対して**
   - 既存ファイルの最新日付を確認
   - 最新日付がある場合：翌日から今日までダウンロード
   - 最新日付がない場合：全期間ダウンロード（新規銘柄）

3. **データマージ・保存**
   - 既存データと新規データを結合
   - 重複削除（日付ベース）
   - 日付順ソート
   - parquet形式で保存

4. **統計情報表示**
   - 処理結果の詳細を表示

## 利点

- **処理時間短縮**: 差分のみダウンロードで大幅な時間短縮
- **通信負荷軽減**: yfinance APIへのリクエスト数を削減
- **データ整合性**: 既存データとの一貫性を保証
- **運用効率化**: 日次・週次更新が現実的に

## 注意事項

- 既存のバッチ処理・統合処理は変更なし
- Google Colab環境での動作を前提
- 通信エラー時は個別銘柄をスキップ（全体処理は継続）
- 上場廃止銘柄は自動的にスキップ
