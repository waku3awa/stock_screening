# バックテスト結果可視化GUI 仕様書

## 1. プロジェクト概要

### 目的
株式スクリーニングシステムのバックテスト実行結果（`src/backtest.py`の出力）を、直感的で分析しやすいGUIで可視化する。

### 対象データ
- **期間**: 2022年1月〜2024年9月（35日分）
- **スクリーニングパターン**: 8種類（pattern1〜pattern8）
- **出力ファイル**: 280の結果ファイル + 35のサマリーファイル

## 2. データ構造分析

### 2.1 サマリーデータ（`summary_16pts_slope5_{日付}.csv`）
| 項目 | 説明 | データ型 |
|------|------|----------|
| Pattern | スクリーニングパターン名（pattern1-8） | string |
| 銘柄数 | 条件に合致した銘柄数 | int |
| 平均リターン(2週間)% | 2週間後の平均リターン | float |
| 勝率(2週間後にプラス)% | 2週間後にプラスになった割合 | float |
| 平均リターン(30日)% | 30日後の平均リターン | float |
| 勝率(30日後にプラス)% | 30日後にプラスになった割合 | float |
| 平均リターン(60日)% | 60日後の平均リターン | float |
| 勝率(60日後にプラス)% | 60日後にプラスになった割合 | float |
| 平均リターン(90日)% | 90日後の平均リターン | float |
| 勝率(90日後にプラス)% | 90日後にプラスになった割合 | float |
| 地合いスコア（当日） | 実行日の市場地合いスコア | int |
| 地合いスコア平均 | 地合いスコアの移動平均 | float |
| 地合いスコア標準偏差 | 地合いスコアの標準偏差 | float |
| 地合いスコア傾向 | 地合いスコアの傾向 | float |
| この日の処理時間(秒) | バックテスト処理時間 | float |

### 2.2 詳細結果データ（`result_pattern{N}_{日付}.csv`）
| 項目 | 説明 | データ型 |
|------|------|----------|
| Ticker | 銘柄コード（4桁数字） | string |
| Name | 銘柄名 | string |
| Return(14d)% | 14日後のリターン | float |
| Return(30d)% | 30日後のリターン | float |
| Return(60d)% | 60日後のリターン | float |
| Return(90d)% | 90日後のリターン | float |

## 3. 技術選択

### 3.1 選択技術: **Streamlit**

#### 採用理由
1. **開発速度**: 圧倒的に速い開発が可能
2. **Python統合**: PandasやPlotlyとのシームレスな連携
3. **データ分析特化**: データサイエンス用途に最適化
4. **プロトタイピング**: 迅速な検証と改善が可能

#### 比較検討結果
| 技術 | 開発速度 | カスタマイズ性 | スケーラビリティ | 適用度 |
|------|----------|----------------|------------------|--------|
| **Streamlit** ⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ | **最適** |
| Dash | ⭐⭐ | ⭐⭐⭐ | ⭐⭐ | 良い |
| PyQt/PySide | ⭐ | ⭐⭐⭐ | ⭐ | 不適 |
| FastAPI+React | ⭐ | ⭐⭐⭐ | ⭐⭐⭐ | 過剰 |

## 4. 可視化設計

### 4.1 メイン分析ビュー

#### パフォーマンス時系列グラフ
- **X軸**: 実行日付（35日分）
- **Y軸**: 平均リターン（%）
- **系列**: 各スクリーニングパターン（8本の線）
- **期間選択**: 2週間/30日/60日/90日のタブ切り替え
- **インタラクティブ機能**: パターンの表示/非表示切り替え

#### 勝率時系列グラフ
- **X軸**: 実行日付
- **Y軸**: 勝率（%）
- **系列**: 各スクリーニングパターン
- **基準線**: 50%ライン

### 4.2 パターン比較ビュー

#### パターン別統計テーブル
- **全期間統計**: 平均/最大/最小リターン、平均勝率
- **期間別統計**: 2週間/30日/60日/90日の統計値
- **銘柄数統計**: 平均/最大/最小銘柄数

#### パフォーマンスヒートマップ
- **X軸**: スクリーニングパターン（8列）
- **Y軸**: 実行日付（35行）
- **色**: 平均リターンまたは勝率の値
- **フィルター**: 期間選択（2週間/30日/60日/90日）

### 4.3 市場環境分析ビュー

#### 地合いスコア分析
- **地合いスコア時系列**: 当日/平均/標準偏差/傾向の推移
- **相関分析**: 地合いスコア vs パフォーマンス
- **散布図**: X=地合いスコア、Y=平均リターン、点=実行日

#### スコア区間別パフォーマンス
- **地合いスコア区間**: [-3, -2, -1, 0, 1, 2, 3] の7区間
- **区間別統計**: 各区間での平均リターン・勝率
- **箱ひげ図**: 区間別リターン分布

### 4.4 詳細銘柄分析ビュー

#### 条件別銘柄詳細
- **フィルター**: 日付選択 + パターン選択
- **銘柄一覧テーブル**: Ticker, Name, 各期間リターン
- **リターン分布ヒストグラム**: 選択条件下での分布
- **上位/下位銘柄**: パフォーマンスランキング

## 6. 技術仕様

### 6.1 依存関係
```
streamlit >= 1.28.0
pandas >= 2.0.0
plotly >= 5.17.0
numpy >= 1.24.0
seaborn >= 0.12.0
matplotlib >= 3.7.0
```

### 6.2 パフォーマンス要件
- **データ読み込み**: 初回読み込み < 5秒
- **グラフ描画**: 各グラフ生成 < 2秒
- **フィルター応答**: UI操作への応答 < 1秒
- **メモリ使用量**: < 500MB（全データ読み込み時）

### 6.3 拡張可能性

#### 新機能追加ポイント
1. **グラフタイプの追加**: `visualizations.py` に関数追加
2. **分析手法の拡張**: `analysis.py` にロジック追加
3. **データソース拡張**: `data_loader.py` の修正
4. **UIコンポーネント**: `components/` に新しい部品追加

#### 設定の外部化
- **色テーマ**: `config/viz_config.py` で管理
- **グラフサイズ**: 設定ファイルで調整可能
- **フィルターオプション**: 動的に設定変更可能
