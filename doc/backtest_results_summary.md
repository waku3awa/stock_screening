## 1. 移動平均収束判定の閾値テスト

### テスト対象（記事4より）
**戦略**: 月利3-5%を狙う自動スクリーニング戦略
**期間**: 複数の市場環境下でのバックテスト
**測定指標**: 月次リターン、シャープレシオ、銘柄選定数

### 閾値別パフォーマンス

| 収束閾値 | 特徴 | 銘柄選定数 | 期待効果 | 実用性 |
|---------|------|-----------|----------|--------|
| **±2%** | 厳密な収束条件 | 少数（高選別） | 高精度選定 | 機会損失リスク |
| **±4%** | 中程度の収束条件 | 中程度 | バランス型 | 安定運用向け |
| **±6%** | 緩い収束条件 | やや多数 | 機会拡大 | ノイズ増加 |
| **±8%** | 最も緩い収束条件 | 多数（幅広捕捉） | 最大機会確保 | 要追加フィルタ |

### 最適化結果の考察

#### 市場環境別の有効性
- **弱気相場（スコア-3～-1）**: より緩い条件（6-8%）が有効
- **中立相場（スコア-1～0）**: 中程度の条件（4-6%）が最適
- **強気相場（スコア+1～+3）**: 厳しい条件（2-4%）でも機能するが不安定

#### シャープレシオ≥0.8の条件
記事4で言及されている「シャープレシオ≥0.8」を満たす戦略パターンの分析：

```
最適条件の組み合わせ例：
- RSI範囲: 25-70

- 市場スコア: -1～0の範囲
- 選定銘柄数: 10-15銘柄/回
```

## 4. 戦略失敗事例と教訓（記事5より）

### 主要な失敗要因
1. **TOPIX連動性への過度依存**
   - 問題: 市場全体の下落時に連動して損失
   - 対策: 非連動銘柄の発掘強化

2. **単純指標の限界**
   - 問題: MA・RSIのみでは市場変化に対応不足
   - 対策: 多様な指標の導入（40-60指標候補）

3. **相場急変への対応不足**
   - 問題: 相場スコア+3時の選定銘柄ゼロ
   - 対策: 市場状況別の戦略切り替え

### 改善計画の方向性
```
短期改善（実装済み）:
├─ MA収束閾値の柔軟化（2%→8%）
├─ RSI範囲の拡張（25-75）
└─ 相場スコア連動戦略

中期改善（計画中）:
├─ PCA活用による次元削減
├─ 非線形指標の導入
└─ 機械学習モデル統合

長期改善（構想段階）:
├─ アンサンブル学習
├─ リアルタイム適応
└─ 外部データ連携
```
